# EE 513 Marco Martinez Corral Assignment 1

This assignment will characterize a Nikon Z50 Camera (NEF format). The application used to capture is the file explorer (Finder) in macOS, as the SD card will be connected directly to the camera.

macOS Native JPG conversion was used for the checkerboard pictures, and the native Nikon JPG conversion was used for the Big Ben and Union Jack images.

Assignment was created/made in a .ipynb Jupyter Notebook file format.
